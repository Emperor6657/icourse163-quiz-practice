# 中国大学MOOC 小测题库练习网页 · 内燃机学

离线单文件的 MOOC 章节小测刷题网页，内置浙江大学《内燃机学》（ZJU-1460864162，第6次开课）10 章小测完整题库 **271 题（含标准答案）**，下载即用、无需联网、无需安装任何依赖。

> [!TIP]
> **在线直接刷题**：<https://emperor6657.github.io/icourse163-quiz-practice/> —— 点开即用，无需下载。
> 想离线使用？下载 [`index.html`](index.html) 双击打开即可（也可拷到手机本地打开）。

## 功能

- **章节练习**：按章节浏览（或全部章节），题目按 单选 → 判断 → 填空 分块排列；每题可作答、单独显示/隐藏答案，也可一键显示全部答案；支持"即时判分"（作答后立即标对错，正确项标绿、错选标红）
- **打乱顺序**：题目在题型内部打乱（不混淆题型块）、选项可独立打乱，切换时已作的答案不会丢失
- **随机抽题**：按章节范围 + 题型（单选/多选/判断/填空）+ 数量随机抽题（不重复），结果按题型分块排列，适合错题重练
- **抽题组卷**：勾选章节并设置每章各题型数量（内置"模拟真实小测 5/5/5"预设），生成试卷并计时；交卷前不显示对错，交卷后输出总分、用时与各题型得分率，正确答案标绿
- 填空题支持多答案判定（如"做功 / 作功"），忽略空格与标点差异

## 题库来源

题库提取自中国大学MOOC平台（icourse163.org）的课程章节小测。学期结束后平台允许"作为自我学习进行"反复练习：每次练习随机抽题，提交后与平台批改结果核对收集，直至各章连续多轮不再出现新题。所有答案均来自平台批改数据（选项正确标记 / 填空标准答案），非人工猜测。

## 重新生成 / 移植到其他课程

```
data/quiz_<测验ID>.json   每章原始题目数据（题型/分值/题干/选项/答案/解析）
build_web.py              py build_web.py   → 生成 index.html（练习网页，即 GitHub Pages 首页）
gen_review.py             py gen_review.py  → 生成 Word/Markdown 复习资料（零依赖）
```

其他课程只需按 `data/` 中的 JSON 格式准备题库数据，即可复用两个脚本（`复习资料/` 内另附本课程的 Word 与 Markdown 版题库）。
